# 2026-10-29

## 修复 dev 起不来：`Can't resolve '@physic/api-client'`

**根因**：`package.json` 把 `@physic/api-client` / `@physic/contracts` 声明为
`file:../physic-platform/packages/*`，但本机不存在 `D:\AnChiProject\physic-platform`，
`node_modules/@physic/*` 是两个指向空目录的死符号链接。本仓库原本是该 monorepo 的兄弟目录，
单独 clone 出来时丢掉了平台包（GitHub 也不可达：代理 127.0.0.1 连不上）。

**处理（用户选择「只求首页能渲染」＝彻底去外部依赖）**：
- 新增 `lib/platform-contracts.ts`：本地类型 `UserPrincipal`、`CanvasBillingOrder`、
  `PolicyConsent`/`PolicyVersions`、`AuthBootstrap`/`AuthChallenge`/`AuthSession`、
  `BillingCatalog`，并保留 `OpenApiComponents` 入口。
- 新增 `lib/platform-api-client.ts`：用原生 fetch 复刻 openapi-fetch 形态的
  `createPlatformApiClient({ baseUrl })` → `{ GET, POST }`，返回 `{ data, error, response }`，
  支持 `params.path/query/header`、`body`、`signal`、`cache`、`credentials: "include"`。
- `lib/user-session.ts` 改为引用本地两个文件，对外导出签名不变。
- `lib/payment-result-state.ts`、`components/auth/auth-form.tsx` 的 import 改本地路径。
- `package.json` 删两个 file: 依赖；`next.config.mjs` 删 `transpilePackages`；
  `package-lock.json` 删两条 `../physic-platform/*` extraneous 条目；`node_modules/@physic` 已清除。

**验证**：`npm run typecheck` 通过、eslint 干净、`/`、`/login`、`/register`、`/points-policy` 全部 200。

**遗留待办**：`Dockerfile.production` 第 20-21 行仍 `npm run build --workspace @physic/contracts`
并 COPY `physic-platform/*`，容器构建会失败，需要单独清理（本次未动）。

**注意**：`next.config.mjs` 的 `outputFileTracingRoot` / `turbopack.root` 都指向父目录
（D:\AnChiProject），与 Docker standalone 布局绑定（`node physic-launch-ui/server.js`），别随手改。
